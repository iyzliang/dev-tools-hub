# Dev Tools Hub - 新工具需求文档

## 一、Grid 网格拖拽布局生成器

### 1.1 功能概述

可视化 CSS Grid 布局设计器，帮助前端开发者通过拖拽操作快速创建网格布局，并生成 CSS 和 Tailwind CSS 代码。

### 1.2 核心功能

#### 基础配置
- **行列设置**：可调节网格行数（1-12）和列数（1-12）
- **间距控制**：支持设置行间距（row-gap）和列间距（column-gap）
- **容器宽度**：可选固定宽度或自适应

#### 区域操作
- **拖拽调整**：鼠标拖拽调整网格区域大小
- **合并单元格**：选择多个单元格进行合并操作
- **命名区域**：为合并后的区域添加自定义名称（用于 grid-template-areas）

#### 对齐设置
- **水平对齐**：justify-items / justify-content
- **垂直对齐**：align-items / align-content
- **区域对齐**：justify-self / align-self

### 1.3 交互设计

#### 工作区布局
- 左侧：控制面板（配置参数）
- 右侧：可视化编辑区（网格画布）
- 底部：代码预览区（可折叠）

#### 操作流程
1. 设置网格行列数量
2. 调整间距和对齐方式
3. 拖拽选择区域进行合并
4. 命名各区域（可选）
5. 实时预览生成的代码
6. 一键复制 CSS 或 Tailwind 代码

### 1.4 代码生成

#### CSS 格式示例
```css
.grid-container {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  grid-template-rows: repeat(2, 100px);
  gap: 16px;
  grid-template-areas:
    "header header header"
    "sidebar main main";
}
```

#### Tailwind 格式示例
```html
<div class="grid grid-cols-3 grid-rows-2 gap-4">
  <div class="col-span-3">Header</div>
  <div class="row-start-2">Sidebar</div>
  <div class="col-span-2 row-start-2">Main</div>
</div>
```

### 1.5 技术实现要点

- 使用 React 状态管理网格配置
- Canvas 或 SVG 实现可视化网格（推荐 SVG，更易交互）
- 支持键盘快捷键（删除、撤销等）
- 响应式设计，移动端支持折叠面板
- 数据本地存储（localStorage），支持保存和加载布局模板

## 二、CSS 阴影效果生成器

### 2.1 功能概述

在线 Box Shadow 生成器，通过滑块实时调整阴影参数，提供多种预设效果，一键生成 CSS 代码。

### 2.2 核心功能

#### 阴影参数
- **水平偏移（X）**：-100px ~ 100px
- **垂直偏移（Y）**：-100px ~ 100px
- **模糊半径（Blur）**：0 ~ 100px
- **扩散半径（Spread）**：-50px ~ 50px
- **颜色**：支持颜色选择器 + 透明度调整
- **内阴影**：可选 inset 属性

#### 预设效果
- **Material Design 系列**
  - Elevation 1-24（Google Material 规范）
- **Neumorphism 系列**
  - 凸起效果
  - 凹陷效果
  - 平滑效果
- **常用效果**
  - 卡片阴影
  - 悬浮效果
  - 边框阴影
  - 柔和发光

### 2.3 交互设计

#### 界面布局
- 左侧：参数控制面板
  - 预设效果选择器
  - 参数滑块组
  - 颜色选择器
- 右侧：预览区域
  - 实时预览框（带阴影的示例元素）
  - 预览元素背景色可调
- 底部：代码输出区
  - CSS 代码展示
  - 一键复制按钮

#### 交互特性
- 所有参数通过滑块调整
- 实时更新预览效果
- 选择预设后自动填充参数
- 支持多层阴影（可选功能）

### 2.4 代码生成示例

#### 单层阴影
```css
box-shadow: 0 4px 6px -1px rgba(0, 0, 0, 0.1), 0 2px 4px -1px rgba(0, 0, 0, 0.06);
```

#### 内阴影
```css
box-shadow: inset 0 2px 4px 0 rgba(0, 0, 0, 0.06);
```

#### Tailwind 格式
```html
<div class="shadow-lg">...</div>
<!-- 或自定义 -->
<div class="[box-shadow:0_4px_6px_-1px_rgba(0,0,0,0.1)]">...</div>
```

### 2.5 技术实现要点

- React hooks 管理阴影状态
- 使用 CSS-in-JS 或 style 属性实时更新预览
- 颜色选择器组件（推荐 react-color 或原生 input[type="color"]）
- 滑块使用原生 range input 或自定义组件
- 支持导出为 CSS 变量格式
- 响应式布局，移动端垂直堆叠

## 四、数据埋点

### 4.1 Grid 布局生成器埋点事件

| 事件名称 | 触发时机 | 事件参数 |
|---------|---------|---------|
| `tool_open` | 页面加载 | `{ tool_name: "grid-layout" }` |
| `grid_create` | 创建新网格 | `{ rows, cols, has_merge }` |
| `grid_merge` | 合并单元格 | `{ cells_count }` |
| `code_copy` | 复制代码 | `{ format: "css" \| "tailwind" }` |
| `preset_apply` | 应用预设 | `{ preset_name }` |

### 4.2 阴影生成器埋点事件

| 事件名称 | 触发时机 | 事件参数 |
|---------|---------|---------|
| `tool_open` | 页面加载 | `{ tool_name: "box-shadow" }` |
| `shadow_preset` | 选择预设 | `{ preset_name, preset_category }` |
| `shadow_adjust` | 调整参数 | `{ param_name, param_value }` |
| `code_copy` | 复制代码 | `{ format: "css" \| "tailwind" }` |
